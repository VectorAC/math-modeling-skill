# 各阶段质量门检查清单

## Phase 1：问题分析

- [ ] 题目拆解是否覆盖所有子问题？
- [ ] 每个假设是否都含合理性说明？
- [ ] 假设是否讨论了不满足的后果？
- [ ] 数据需求是否明确定义？
- [ ] 关键约束是否识别？

## Phase 2：模型设计

- [ ] 每个子问题是否≥2 种方案对比？
- [ ] 每种方案是否提供了 AI/CS 和统计/数学两种风格对比？
- [ ] 是否说明了 Why 而非只说了 What？
- [ ] 数学表达是否完整（变量+函数+约束）？
- [ ] 是否提供了学习资源（当用户不理解时）？
- [ ] 方案选择是否经过用户确认？

## Phase 3：建模实现

- [ ] 代码是否可运行？
- [ ] 依赖声明是否完整（库名+版本）？
- [ ] 结果是否通过了合理性检查（数量级+边界）？
- [ ] 可视化是否规范（图注+坐标轴+配色）？
- [ ] 关键参数是否集中配置、不硬编码？
- [ ] 代码是否被审查过？

## Phase 4：论文写作

- [ ] 摘要结构是否完整（数据→模型→结论→灵敏度→意义）？
- [ ] 是否有明显的 AI 痕迹段落需要修改？
- [ ] 每张图表后是否有分析文字段落？
- [ ] 参考文献是否真实可查？
- [ ] 每处引用是否说明了"引了什么+为什么引"？
- [ ] 国赛：算法是用流程图呈现而非伪代码？
- [ ] 美赛：Summary Sheet 是否符合 250-350 词规范？
- [ ] 每个假设是否附了合理性论证？
- [ ] 章节间是否有承上启下的过渡？
- [ ] 模型评价是否有量化指标？

## Phase 5：最终验证

- [ ] 结果数量级和单位是否正确？
- [ ] 灵敏度分析是否覆盖参数和权重两个维度？
- [ ] 格式是否符合比赛规定？
- [ ] 所有图表是否都有编号且正文有引用？
- [ ] 推荐策略是否具有实际可操作性？
- [ ] 参考文献完整且格式统一？
- [ ] 美赛：总页数是否在 25 页以内？
- [ ] 美赛：AI 使用报告是否包含？
