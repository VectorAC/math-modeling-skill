# 各阶段质量门检查清单

## Phase 0：初始化

- [ ] 比赛模式已检测并获用户确认（国赛/美赛/通用，无明确倾向时默认国赛）？
- [ ] 技术栈已锁定（Python/MATLAB/LINGO/R，用户确认，不代选）？
- [ ] 依赖 skill 状态明确（缺失项已说明功能+为什么需要+安装方式）？
- [ ] 需求四项已逐条确认（题目理解/方法偏好/数据情况/输出要求）？
- [ ] 项目文件夹位置已与用户确认（**未确认前不创建任何项目目录**）？

## Phase 0.5：题目信息获取

- [ ] 每个输入文件都有抽取结果，且状态明确（成功/空/扫描版）？
- [ ] 题目原文完整无删改？
- [ ] 关键数字、数据表齐全？
- [ ] 存疑项已列清单并给出处理建议？
- [ ] 用户已确认信息卡内容？

## Phase 1：问题分析

- [ ] 题目拆解是否覆盖所有子问题？
- [ ] 每个假设是否都含合理性说明？
- [ ] 假设是否讨论了不满足的后果？
- [ ] 数据需求是否明确定义？
- [ ] 关键约束是否识别？
- [ ] **硬约束清单是否逐字摘录（不转述）？**
- [ ] **关键统计数字是否有探索输出文件支撑？**
- [ ] **出口交互门是否执行（用户确认无补充后才通过）？**
- [ ] **思考路径节是否每个子问题四步齐全（观察点/试探与发现/解决与转化/引申一问）？**
- [ ] **思考路径节是否含 ≥1 个转折点、不以结论开头？**
- [ ] **思考路径节是否落到公式层（理论核心公式 + 代入本题参数的计算）？**

## Phase 2：模型设计

- [ ] 每个子问题是否≥2 种方案对比？
- [ ] 每种方案是否提供了 AI/CS 和统计/数学两种风格对比？
- [ ] 是否说明了 Why 而非只说了 What？
- [ ] 数学表达是否完整（变量+函数+约束）？
- [ ] 是否提供了学习资源（仅当用户提问时）？
- [ ] 方案选择是否经过用户确认？
- [ ] **方案前交互门（补充约束确认）与方案后确认（选哪个）是否执行？**
- [ ] **每个候选方案是否有创新点阐述（标准方法无创新时是否给出：如何创新/为什么好/如何实现/难度）？**
- [ ] **选定方案后是否产出创新点陈述（灵感+核心构成+与常规区别）并写入 checkpoint？**
- [ ] **思考路径节是否衔接 Phase 1 叙事（首句"上一阶段我们发现……"）？**
- [ ] **思考路径节是否覆盖完整决策链（候选为何提出/为何被否被选/转折点）且落到公式层？**

## Phase 3：建模实现

- [ ] 代码是否可运行？
- [ ] 依赖声明是否完整（库名+版本）？
- [ ] 结果是否通过了合理性检查（数量级+边界）？
- [ ] 可视化是否规范（图注+坐标轴+配色）？
- [ ] 关键参数是否集中配置、不硬编码？
- [ ] 代码是否被审查过？
- [ ] **冒烟测试是否先于全量运行（1% 规模跑通 + 硬约束核对）？**
- [ ] **长任务是否拆片（>30min → ≤40min 片 + checkpoint 断点续算）？**
- [ ] **每片结束是否向用户汇报（进度/问题/原因/解决计划）？**
- [ ] **图注（类型/库/函数/参数）是否不在图内、不进正文？**
- [ ] **制图是否 MATLAB 优先？**

## Phase 4：论文写作

- [ ] 摘要结构是否完整（数据→模型→结论→灵敏度→意义）？
- [ ] 方法篇幅:结果篇幅 ≤ 1:1？每段至少 1-2 个量化结果？
- [ ] 关键词是否全为模型名/方法名（无通用词）？
- [ ] 是否有明显的 AI 痕迹段落需要修改？
- [ ] 每张图表后是否有分析文字段落？
- [ ] 每张图/表在正文中是否有显式引用？
- [ ] 参考文献是否真实可查？正文中是否有引用标记？
- [ ] 每处引用是否说明了"引了什么+为什么引"？
- [ ] 国赛：算法是用流程图呈现而非伪代码？
- [ ] 美赛：Summary Sheet 是否符合 250-350 词规范？
- [ ] 每个假设是否附了合理性论证？
- [ ] 章节间是否有承上启下的过渡？
- [ ] 模型评价是否有量化指标？
- [ ] 全篇公式是否都有编号和引导句？
- [ ] 全文术语是否一致（同一概念不出现两个说法）？
- [ ] **写作前必读是否按赛区完成（美赛：2401445 必读 + 同题型 1-2 篇按需；国赛：检索相关 1-2 篇）？跳过篇目是否写明理由？**
- [ ] **是否已输出语言锁定声明且全文规范一致（中英不混用）？**
- [ ] **每个问题是否按理论/结果二分撰写（理论含流程图+三线表，结果仅数据可视化）？**
- [ ] **结果部分是否误用流程图？**
- [ ] **`\cref{}` 前是否没有"图/表/假设"前缀？**
- [ ] **中文引号是否用 “”（非英式直引号）？**
- [ ] **符号说明是否直接三线表且不参与编号？**
- [ ] **三线表是否都有 `\setlength{\tabcolsep}{}`？**
- [ ] **间距统一是否含假设环境行距（假设内部/假设间/正文行距一致，无空行/\\/itemize 额外间距）？**
- [ ] **长表是否已处理（>12 数据行或超半页 → 核心列+附录或整体附录）？**
- [ ] **摘要公式数量是否在限制内（国赛 ≤2 / 美赛 ≤3）？**
- [ ] **多人模式：paper-framework.md 是否先于部件生成且每个分发文件夹有副本？交回/ 目录是否已创建？**
- [ ] **正文是否无"创新点/我们创新地"字样（创新强调只在 Phase 2 给方案时）？**
- [ ] **内容去重：正文内有无跨章节无增量重复叙述？**
- [ ] **references-notes.md 是否已生成（每篇文献：标题 | 来源网站+检索词+日期 | 用了什么思维）？**
- [ ] **flowchart-notes.md 是否已生成（每张流程图一个要点块）？**
- [ ] **tex 注释是否精简（每节只留 1 行锚点注释，无解释性绿注释）？**
- [ ] **是否提醒用户自行记录 AI 交互（不代记）？**

## Phase 5：最终验证

- [ ] 结果数量级和单位是否正确？
- [ ] 灵敏度分析是否覆盖参数和权重两个维度？有图表支撑？
- [ ] 格式是否符合比赛规定？
- [ ] 所有图表是否都有连续编号且正文有引用（100%）？
- [ ] 图编号在代码和 LaTeX 之间是否对齐（无错位）？
- [ ] 所有公式是否都有编号和引导句？
- [ ] 全文术语是否一致（无"遮蔽/遮挡"混用）？
- [ ] 推荐策略是否具有实际可操作性？
- [ ] 参考文献完整且格式统一？每篇在正文中有引用？
- [ ] 美赛：总页数是否在 25 页以内？
- [ ] 美赛：AI 使用报告是否包含？
- [ ] 美赛：有目录页、独立 Assumptions、符号说明表？
- [ ] **声称存在的文件（PROGRESS.md 等）是否真实存在于磁盘？**
- [ ] **三方核对是否执行——先跑 tricheck.py（checkpoint tri_check 段 vs main.tex），FAIL 定位修改、MANUAL 人工复核？**
- [ ] **页数/图数等是否以实际编译产物为准（preflight --log 自动解析）并回写 checkpoint？**
- [ ] **多人模式：组装产物验证是否完成（三件套齐全、结构与 paper-framework.md 一致）？**
- [ ] **多人模式：跨部件一致性检查是否完成（label 前缀 / 跨部件引用 / 术语与间距 / 锚点结构）？**
- [ ] **长表是否已处理（>12 数据行或超半页版心 → 核心列+附录或整体附录）？**
