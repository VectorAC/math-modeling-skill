# 组装空间 — 行为规则

## 触发方式

当用户说出以下任一内容时，你立即切换至组装空间模式：
- 「组装空间」
- 「组装论文」
- 「把部件拼成论文」
- 「部件都改完了，合成一篇」

## 背景

多人协作时，论文按题拆成部件（Q1/Q2/Q3/公有），每人负责一个部件文件，改完后交回。组装空间的职责：**把部件按模板结构拼成一篇完整论文并正确编译出 PDF，不改变任何正文内容**（文字/数字/公式/图片一律冻结）。

## 核心原则

**内容冻结。** 组装过程只允许修改结构命令；任何对正文内容（文字、数字、公式、图片）的修改都必须上报用户决定，绝不静默修改。

## 输入

- 部件文件：`part_q1.tex` … `part_qN.tex`（N = 题目数量）+ `part_common.tex`（命名约定见 `references/assembly/part-template.tex`）
- 主模板：`references/cumcm-template/cumcm2025_template.tex` + `cumcmthesis.cls`
- 图片文件（各部件引用的 figures）
- 分发文件夹（`part_q1_分发/` 等，含 README / 背景材料 / code_qN）**只作分发参考，不参与组装**——组装只接收部件文件、模板与图片

## 执行步骤

### 1. 组装清单先行（强制）
先产出「锚点 → 文件」映射清单，顺序即模板章节顺序：

```
摘要（问题一→二→三句组）→ 问题重述（各题）→ 问题分析（各题）→
假设 → 符号说明 → 模型准备 → 问题一建模求解 → 问题二 → 问题三 →
模型测试与分析（灵敏度）→ 模型评价 → 参考文献 → 附录（各题代码）
```

每个锚点对应哪个部件文件的哪个片段。**先展示给用户确认，确认后才动手拼。**

### 2. 拼接
- 创建论文目录，复制模板 + `.cls` + 图片
- main.tex 按模板结构写 `\input{part_q1.tex}` 等（每个部件内部按锚点注释分片段，\input 整个部件文件即可）
- 部件文件**禁止**包含 `\documentclass` / `\begin{document}` / `\usepackage` / `\newenvironment`（只在 main.tex），违者视为违规需先移除并上报

### 3. 编译
- `latexmk -xelatex`（或 xelatex 两遍）
- 编译错误 → 分类处理（见下方白名单）

### 4. 结构修复白名单（只能改这些）
| 可修改 | 示例 | 禁止（必须上报） |
|--------|------|------------------|
| `\input` 位置/顺序 | 调整片段插入位置 | 修改正文文字、数字、公式 |
| label 重命名 | `\label{fig:xx}` 冲突时加前缀 `q1:` | 修改图片内容/尺寸语义 |
| 宏定义去重 | 多个部件重复 `\newcommand` → 移到 main.tex | 新增/删除正文段落 |
| 图片路径 | 大小写/扩展名/路径修正 | 改动表格数据 |
| 补 `\usepackage` | 缺宏包时在 main.tex 侧补 | 补充/改写摘要句子 |
| `\ref` 悬空修复 | 报告缺失 label，不静默补定义 | 修改参考文献列表 |

任何需要动正文才能过的编译错误 → 上报用户：「错误位置 + 原因 + 需要的修改」，由用户决定。

### 5. 交付
- **结构 diff 报告**：列出所有改动（加了哪些 \input、改了哪些 label、修了哪些编译错误），用户可逐条核对内容未被改动
- 校验清单：
  - [ ] 编译 0 错误（允许 <8pt 的 overfull 警告）
  - [ ] 图/表/公式编号连续、引用率 100%（无悬空 \ref）
  - [ ] 页数与各部件预览拼接后的预期一致（±2 页）
  - [ ] 无重复 label、无重复宏定义
  - [ ] 摘要顺序：问题一→二→三句组连贯
  - [ ] AI 交互日志（ai_usage_log.md）已并入论文 AI 使用说明附录

## 红线

- 绝不修改正文内容（文字/数字/公式/图片）
- 绝不静默修复——每个结构修改都进 diff 报告
- 部件文件缺失/含文档级命令 → 先上报再处理
- 组装完成 = PDF + diff 报告 + 校验清单三件套，缺一不算完成

## 与正常模式的切换

用户说「继续任务」「回到正常流程」时退出组装空间。

## AI 交互记录

组装空间内的每次问答追加到统一的 AI 交互日志 `.claude/math-modeling/ai_usage_log.md`。
